Executive Summary

Captures digital handwritten responses from canvas interfaces and processes them through an integrated OpenCV + PaddleOCR neural pipeline.

Market Need

Why Digitize Handwritten Answers?

Conventional Answer-Sheet Challenges
  • Manual handling and sorting of physical answer sheets
  • Time-consuming manual data entry and transcription
  • Unstructured handwriting hinders machine processing
  • Question-wise answer extraction is difficult on physical paper
  • Requires significant human effort prior to evaluation
Process Comparison
Traditional: Physical Sheet ➔ Manual Reading ➔ Manual Entry ➔ Evaluation
Proposed: Digital Canvas ➔ Preprocessing ➔ PaddleOCR ➔ Digitized Text
Key Benefit: Significantly reduces manual data-entry dependency and creates structured digital records.

Architecture

System Architecture

🖥️ Student Canvas (React + Vite Frontend)
↓ POST /api/v1/student/answer-sheets
⚙️ Node.js + Express Backend Server
↓ Asynchronous HTTP Payload
🐍 FastAPI Python OCR Service (Port 8000)
↓ Image Preprocessing & PP-OCRv5
💾 MongoDB Persistence (AnswerSheet Collection)
Component Responsibility
Frontend: Captures vector handwriting strokes and question assignments.
Backend: Orchestrates API authentication, status management, and job queues.
OCR Service: Executes OpenCV preprocessing and PaddleOCR 3.7.0 neural inference.
Database: Persists raw strokes, generated images, transcribed text, and confidence levels.

API Response Attributes
extractedText: Concatenated transcribed text stored in MongoDB.
confidence: Neural confidence metric generated by PP-OCRv5 head.
executionTimeSec: Total latency for stroke rendering & inference.
hwrStatus: Completion flag for background job polling.
